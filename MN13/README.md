# MN13 內容管理

管理頁：`admin.html`。資料：`content.json`。前台：`MN13.html`、`content.js`。

此管理頁只對 `m13nbeauty/MN13` 的 `main` 分支寫入 `MN13/content.json` 和 `MN13/media/`，不使用 MR 的儲存庫、Notion 內容或資料庫。

## 首次發布設定

1. 以具有 MN13 儲存庫寫入權限的 GitHub 帳號登入 GitHub。
2. 建立 fine-grained personal access token，只選擇 `m13nbeauty/MN13`，Contents 設為 Read and write。設定適當到期日。
3. 在管理頁的「連接 MN13 發布權限」貼入權杖。不要將權杖傳送給他人或寫入檔案。
4. 新增或修改課程、日誌，儲存草稿並確認內容後，按「發布到官網」。GitHub Pages 部署有延遲，待部署完成後重新整理官網。

權杖只在 JS 記憶體保存，不寫入 localStorage、資料檔或網址。重新整理後需重新連接。沒有權杖的人可看到管理介面和公開資料，但不能寫入 GitHub。草稿保存於本機瀏覽器，超過空間時需下載備份。照片原檔及資料都存放於公開儲存庫；不適合存放客人聯絡方式、未授權照片或私密紀錄。刪除公開內容不會刪除既有 Git 歷史。

發布會先比較載入版本與目前資料版本，將 JSON 和新照片寫入同一個 Git commit，再以非 force 更新分支。若多人編輯或版本變更，發布會停止以避免覆蓋他人的修改。

## 編輯欄位

課程：名稱、分類、簡短介紹、完整介紹、最多 10 張圖片、顯示順序、顯示狀態、檢查備註。

肌膚日誌：名稱、標籤、紀錄間隔、兩次紀錄日期、兩張照片、各自說明、日誌文字、顯示順序、顯示狀態、公開同意確認。未確認公開同意的日誌不呈現在前台。既有四份紀錄的同意欄位依原官網文字遷移，並非此更新重新查驗了同意文件。

## 2026-10-04 文案檢查

查核目前可取得的台灣官方規定；全國法規資料庫整編截止日期 2026-09-24。適用規範須依實際商品、服務、設備與操作個案判斷，不存在一份通用的「美業法」能涵蓋所有情形。

- 化粧品衛生安全管理法第 10 條，以及化粧品標示宣傳廣告涉及虛偽誇大或醫療效能認定準則第 2–5 條：對化粧品廣告，判斷文字、圖片等整體表現；不實、無足夠證據及醫療效能宣稱須避免。通常可用詞句也應符合實際產品種類及內容。
- 醫療法第 84、87 條：非醫療機構或醫師不得為醫療廣告；暗示或影射醫療業務也可能屬醫療廣告。
- 公平交易法第 21 條及公平會處理原則：商品或服務廣告不得虛偽不實或引人錯誤。

本次移除或改寫排毒、疏通氣結、廢液排除、深入導入、保證成效等訴求，調整「斑點剋星」等較強的名稱。沒有新增價格、課程時間、師資資格、產品核准情形或課程成果。

待確認：Plasma 的型號、用途與操作資格；駐顏粉底是否涉及針具或侵入性操作；外泌體產品成分來源及合法供應文件。源自人體細胞的外泌體另有個案審查要求，不能把所有不同來源的外泌體概括判為合法或違法。

Notion 提供的作品集頁面尚未取得讀取權限。現有課程圖片先保留，因此本次不代表圖片宣稱已全部檢查通過，也沒有依不可讀的作品集推測新增課程。待取得兩個作品集原始資料後，須比對課程、更新圖片並檢查圖片中文字。
